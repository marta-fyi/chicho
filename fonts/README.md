# Fonts

`Satoshi-Variable.woff2` is Satoshi by Indian Type Foundry, from Fontshare (https://www.fontshare.com/fonts/satoshi),
one variable file covering weights 300 to 900. Chicho uses 400 and 500.

It is licensed under the Fontshare Free Font License (FFL), which allows self-hosting on your own website through
`@font-face` but not modifying the file: no subsetting, no format conversion, no renaming. So the file here is the one
Fontshare ships, byte for byte (`tools/make-fonts.sh` copies it and checks it is identical).
